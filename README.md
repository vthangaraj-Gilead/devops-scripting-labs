# DevOps Scripting Labs

This repository contains a curated set of DevOps scripting exercises implemented using **Bash** and **Python**.

The goal of this repository is to build and demonstrate **operational scripting capability** — not language mastery — by solving common, real-world DevOps scenarios typically encountered in Linux and AWS environments.

The problems are designed to progress from **very basic to mid-level complexity**, focusing on:
- System observability
- Safety checks
- Audits and reporting
- Glue automation for operations

---

## Why This Repository Exists

In many DevOps roles, scripting is required to:
- Reduce repetitive operational work
- Perform quick audits and validations
- Improve reliability and consistency
- Support incident triage and investigation

This repository represents **intentional skill development** through representative operational scenarios, rather than production-ready tooling.

---

## Scope & Design Principles

- Linux-first scripting
- AWS (read-only where applicable)
- Bash-first approach, Python used when logic or data handling becomes complex
- Emphasis on correctness and clarity over optimization
- No destructive automation

---

## Repository Structure

devops-scripting-labs/ ├── README.md ├── problem-01/ ├── problem-02/ ├── ... └── problem-10/


Each problem directory contains:
- A problem-specific README
- One or more Bash scripts
- Optional Python implementation

---

## How to Use This Repository

- Each problem is self-contained
- Problems can be solved independently
- Scripts are intentionally kept simple and readable
- Solutions prioritize learning and understanding over best-in-class design

---

## Disclaimer

These scripts are created for learning and demonstration purposes.
They should be reviewed, adapted, and tested before any real-world usage in production environments.
